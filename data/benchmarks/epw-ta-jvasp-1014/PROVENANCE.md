# Tantalum EPW benchmark (Stage 1 package)

Stage 1 checks the **method**: run tantalum, a superconductor whose
electron-phonon numbers are already published, and see whether this setup
reproduces them. The reference is JARVIS-SuperconDB entry JVASP-1014:
λ = 0.7572 and ωlog = 164.99 K. The result is compared with that and is never
added to training.

Unlike the lead package, these inputs were written for this project. The
settings and the checks behind them are below.

## Pseudopotential

| Item | Value |
| --- | --- |
| File | `pp/Ta_ONCV_PBE_sr.upf` |
| Source | https://github.com/pipidog/ONCVPSP, file `abinit/Ta_ONCV_PBE_sr.upf`, fetched 2026-11-11 |
| Kind | Norm-conserving (ONCV), scalar-relativistic, PBE, with a core correction |
| Valence | 13 electrons: 5s² 5p⁶ 5d³ 6s² |
| Made with | ONCVPSP 3.3.0 from the Abinit/PseudoDojo v0.4 input for Ta, as the file's own header records |
| License | The header asks for a citation of D. R. Hamann, Phys. Rev. B 88, 085117 (2013); ONCVPSP is GPL |

This is a third-party copy, regenerated by the repository's author from the
published input, not a download from the PseudoDojo site (which this project's
build environment could not reach). It was therefore tested before use:

| Check (4 cores, QE 7.6) | Result |
| --- | --- |
| Total energy against cutoff, 40 to 100 Ry | Converged to 0.1 mRy by 60 Ry; pressure steady to 0.1 kbar from 60 Ry. The inputs use 70 Ry |
| Lattice constant at zero pressure, 16×16×16 k-points | 6.2736 bohr = 3.320 Å (measured 3.30 Å; this functional usually gives about 3.32 Å) |
| Phonons at the zone boundary (smoke mesh) | 98 to 151 cm⁻¹ at N and 181 cm⁻¹ at H. Neutron measurements put tantalum's zone-boundary modes at roughly 90 to 170 cm⁻¹, so these are within about 10% |

## Settings

| Setting | Value | Why |
| --- | --- | --- |
| Cell | bcc, `celldm(1) = 6.2736` bohr | The zero-pressure lattice for this pseudopotential, so phonons are computed at equilibrium |
| Smearing | Marzari-Vanderbilt, 0.02 Ry | A standard choice for metals |
| Phonon k-mesh, q-mesh | 16×16×16, 4×4×4 (8 irreducible q-points) | |
| EPW coarse k-mesh | 8×8×8, listed in full in `epw/nscf.in`, 14 bands | Must contain the q-mesh |
| Wannier functions | 6: the five 5d and one 6s orbital (`proj = 'Ta:d'`, `'Ta:s'`) | Bands 5 to 10 are the s-d complex that crosses the Fermi level |
| Skipped bands | 1 to 4 | The 5s and 5p semicore states, 33 and 67 eV below the Fermi level |
| Energy windows | Outer 9 to 28 eV; frozen 9 to 26 eV (Fermi level 18.1 eV) | Band 11 starts at 26.6 eV, so the frozen window holds exactly the six wanted bands; the outer window reaches the top of band 10 at 27.4 eV |
| Fine meshes | k 24×24×24, q 12×12×12, `fsthick = 0.4` eV, `degaussw = 0.1` eV | |

The windows are absolute energies and belong to this pseudopotential and
lattice constant. Change either and they must be found again from the band
energies.

`epw/nscf.in` must not contain `nosym = .true.`. With it, `epw.x` from QE 7.6
stops with `free(): invalid pointer` and no explanation. The chain script
refuses such an input.

`phonons/pp.py` is the same file as in the lead package: Quantum ESPRESSO's
`EPW/examples/pb/woSOC/phonons/pp.py`, commit `61569eb`, GPL v2.

## Files added for the pipeline

- `ta-bcc.cif`: bcc tantalum with a = 3.31985 Å, the same lattice as the inputs.
- `review.template.json`: copy to `results/ta-jvasp-1014/review.json` after the run and fill it in.
- `chain.conf` and `smoke-edits.tsv`: read by `scripts/hpc/submit_epw_chain.sh`.

Run it with `scripts/hpc/submit_stage1_ta.sh`. Rehearsal results are in
`docs/hazel-runbook.md`, section 7.

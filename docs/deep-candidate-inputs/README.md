These CIFs are reproducible calculation inputs and ML-relaxed outputs, not experimentally observed candidate structures. The shortlist CSVs link each file to its content hash and source lineage. Occupationally disordered inputs are preserved for expert ordering decisions.

Parent data: [3DSC](https://doi.org/10.1038/s41597-023-02721-y) and [JARVIS-SuperconDB v4](https://doi.org/10.6084/m9.figshare.21370572.v4). Retain attribution to those sources. Substitution and relaxation methods, software versions and hashes are recorded in `docs/deep-phase4-campaign.json` and `docs/deep-dynamic-stability.json`.

`al-control.cif` is the fcc Al numerical control. CHGNet's imaginary-mode signals for this control were false positives, so candidate ML signals are diagnostic rather than validated instability verdicts.
